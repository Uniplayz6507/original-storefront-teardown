# Original Storefront Teardown

An educational teardown clone of a game storefront, built with original branding, original copy, and generated placeholder artwork. It is not affiliated with or endorsed by Valve or Steam, and it does not use Valve logos, wordmarks, scraped store text, or copyrighted store imagery.

## Run it

Open `index.html` directly in a browser. No build step or backend is required.

## Included flows

- Featured storefront home with rotating spotlight and curated shelves
- Live search with tags, platform, review score, and price filters
- Game detail view with media tabs, description, requirements, reviews, and related games
- Client-side cart and mock checkout flow
- Library grid with an in-library detail view
- Profile/account view
- Responsive desktop and mobile layouts

## Notes

The app uses a lightweight in-memory state layer with localStorage persistence for cart, library, and profile actions. All products, artwork, ratings, prices, and descriptions are fictional.
